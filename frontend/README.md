# Reciptor — frontend

React + TypeScript + Vite client for the Reciptor OCR receipt scanner.

See the [project README](../README.md) for the full stack, setup
instructions and local-environment notes.

Quick start:

```powershell
npm install
npm run dev      # http://localhost:5173, talks to backend on :8000
npm run build    # production build + type-check
```
